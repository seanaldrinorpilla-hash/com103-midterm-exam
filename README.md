How to Run and Use the Program

Open your terminal and navigate to the folder where the file is saved, 
then type python expense_tracker.py and press Enter to start the program. 
When prompted with Student name:, type your name and press Enter. 
When prompted with Weekly budget:, type your budget amount (e.g. 500) and press Enter.
A category menu will appear automatically on the screen — read it to know which number belongs to which category. 
The program will now ask for up to 4 expenses. For each one, type a number 1 to 5 at the Category (0 to skip): prompt and press Enter.
Type a short description of your expense at the Description: prompt and press Enter. 
Type the amount you spent at the Amount: prompt and press Enter. 
If you do not want to log an expense for that slot, just type 0 at the Category (0 to skip): prompt and press Enter to skip it. 
Repeat steps 5 to 8 until all 4 expense slots are done. 
The expense report will print automatically showing each expense, total spent, remaining budget, and a status message. 
Any single expense that exceeds 25% of your weekly budget will be marked with ! High Expense Alert!
